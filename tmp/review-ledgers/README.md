# Private PR model-review ledgers

These shared working notes record broad subagent review evidence outside the FireMUD implementation worktrees. Use one file per PR. They supplement the PR body and do not replace canonical design, tracker, CI, or CodeRabbit evidence.

For each complete broad pass, append the reviewed head and assigned domain, raw/useful finding counts, concise findings with fixed/routed/rejected dispositions, remaining gaps, and why another pass is useful. A narrow investigation is labelled separately and does not count as a broad pass. Record only evidence actually observed; do not reconstruct counts by guesswork. Keep the format short enough for Overseer to inspect quickly.

Workers edit only their assigned PR ledger. Overseer snapshots these notes on the private project-direction branch; no worker needs to commit or publish the ledger during an active review.
