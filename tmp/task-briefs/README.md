# Overseer task briefs

This directory holds durable assignments for substantial cross-task work. Each brief is the authority that survives chat compaction and worker restarts.

- Create one Markdown file per continuing assignment.
- Record scope, exact starting state, topology, constraints, review rules, stopping conditions, validation, and handoff evidence.
- Append dated follow-up sections instead of rewriting prior instructions.
- Mark superseded instructions explicitly and name their replacement.
- If accumulated amendments become conflicting or difficult to execute, rewrite the brief as one current assignment. Tell the worker that the brief is realigned, summarize changed or removed instructions, and make the rewritten brief authoritative over earlier chat messages.
- Send workers concise chat messages that link the exact absolute file and identify the section to read.
- Keep detailed findings in the owning PR body or ledger when that is already their canonical home; the task brief should link those records instead of copying them.
