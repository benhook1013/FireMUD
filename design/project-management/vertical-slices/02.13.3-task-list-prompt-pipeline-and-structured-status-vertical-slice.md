# Prompt Pipeline and Structured Status Vertical Slice Task List

## Goal and Status

Goal: turn prompt/state handling into a real first-class pipeline with coalescing, structured status delivery, and future support for game-defined and player-configurable prompt composition. Status: planned.

## Scope

- Prompt coalescing after output bursts
- Fresh prompt emission after reconnect restore
- Structured prompt/status delivery for first-party web later
- Game-defined and player-configurable prompt field composition hooks

## Key Tasks

- [ ] Implement the first real prompt-coalescing policy rather than treating prompts as only a distinct output class.
- [ ] Ensure reconnect behavior remains:
  - transcript buffer;
  - fresh `LOOK`;
  - one fresh prompt.
- [ ] Define the first structured prompt/status payload shape for non-text clients.
- [ ] Document or prototype how game-defined status fields and player-selected prompt composition will plug into the prompt pipeline later.
- [ ] Keep prompt text rendering for classic clients as one renderer over the same structured prompt/status model.

## Tests

- [ ] Add prompt-burst tests that prove one coalesced prompt rather than prompt spam.
- [ ] Add reconnect tests showing prompt exclusion from transcript replay and fresh prompt regeneration afterward.

## Notes

- Prompt handling should remain distinct from transcript history.
- This slice should not hardcode one universal prompt format across all games.
