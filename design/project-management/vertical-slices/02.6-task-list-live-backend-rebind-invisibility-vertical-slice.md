# Live Backend Rebind Invisibility Vertical Slice Task List

## Goal and Status

Goal: make Game Session and other non-edge gameplay restarts operationally invisible to already-connected clients in the common case by rebinding backend handling behind the live edge socket, so the player experiences at most a brief stall instead of a forced reconnect. Status: planned.

This slice intentionally follows `02.5`. It assumes reconnect-critical coordination state has already been externalized enough that a replacement same-type instance can reconstruct responsibility safely from shared state.

## 1. Rebind Model

- [ ] Define the canonical rebind model for an already-established edge connection when its current Game Session instance disappears.
- [ ] Make explicit which parts of the bridge stay edge-owned and which parts may be rebound to a replacement backend instance.
- [ ] Keep the model honest about the bounded loss envelope for in-flight commands or outputs during the switchover.

## 2. Game Session Restart Invisibility

- [ ] Ensure a Game Session restart causes at most a bounded stall for an already-connected client rather than a visible `LOGIN` / `PLAY` cycle.
- [ ] Reconstruct any backend-local handling needed from shared state rather than relying on the dead instance.
- [ ] Keep existing edge-visible taxonomy only for the cases where the edge route itself really dropped.

## 3. Game Logic Restart Invisibility

- [ ] Apply the same principle to Game Logic restart where command/tick ownership is already externalized.
- [ ] Ensure the client sees current-state continuity after the stall rather than a replay fantasy.

## 4. Regression Coverage

- [ ] Add one focused proof for Game Session restart invisibility.
- [ ] Add one focused proof for Game Logic restart invisibility.
- [ ] Keep the suite bounded and operationally meaningful; do not turn it into generalized chaos testing.

## 5. Final QA Checklist

- [ ] Manually verify one Game Session restart and one Game Logic restart while a client remains connected at the edge.
- [ ] Confirm the player sees continued gameplay after a brief stall rather than a forced explicit reconnect flow.
