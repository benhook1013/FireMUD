# Communication Recipient Delivery Vertical Slice Task List

## Goal and Status

Goal: turn the structured per-recipient communication views from `04.4` into real recipient-side runtime delivery so targets and observers can receive their own rendered transcripts over Telnet, WebSocket, and later first-party/MCP-aware clients. Status: planned.

This follow-up exists because the current shared communication path only returns actor-side output synchronously. `04.4` establishes the authoritative recipient-view model first; this slice makes that model visible to non-actor clients.

## 1. Delivery Boundary

- [ ] Decide and document the runtime path for recipient-side communication delivery:
  - direct Game Session push,
  - Social & Groups-mediated fanout,
  - or another bounded internal bus.
- [ ] Ensure Game Session consumes structured recipient views from Game Logic instead of inventing target/observer prose locally.

## 2. Target Delivery

- [ ] Deliver target-side views for `WHISPER` and `TELL` to live recipients.
- [ ] Ensure sender, target, and non-recipients each receive only the intended transcript.
- [ ] Add WebSocket and Telnet examples proving target-side delivery.

## 3. Observer Delivery

- [ ] Deliver metadata-only observer views for the `WHISPER` observer mechanic from `04.4`.
- [ ] Ensure observers do not receive full content unless a later capability explicitly upgrades them.
- [ ] Keep the observer path separately testable from ordinary target delivery.

## 4. Persistence and Audit

- [ ] Decide whether recipient-side target and observer deliveries are persisted distinctly, transient only, or persisted with recipient-view metadata.
- [ ] Align Social & Groups and moderation docs with the chosen delivery/persistence rule.

## 5. Regression Coverage

- [ ] Add focused cross-service tests for sender, target, and observer delivery over both Telnet and WebSocket.
- [ ] Confirm the service path remains coherent:
  - Game Session -> Game Logic -> Social & Groups where applicable -> recipient delivery back through Game Session.
