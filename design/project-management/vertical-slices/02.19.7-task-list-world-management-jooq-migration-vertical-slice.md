# World Management jOOQ Migration Vertical Slice

## Goal and Status

Goal: migrate `world-management-service` onto `jOOQ + Flyway` so world design/runtime topology persistence follows the repo’s explicit SQL standard instead of remaining one of the last large JPA-backed model graphs. Status: planned.

## Scope

- replace JPA repository/entity seams across world, zone, region, room, instance, generation-rule, and design-epoch persistence with `jOOQ`;
- preserve the current Flyway baseline and world-management contracts;
- remove JPA/Hibernate runtime/config dependencies from the service.
