# Design Capability Allocation System

Status: Current read-only allocation inventory for the architecture Markdown corpus. Product requirements and observable product behavior are allocated in the product section of the top-level design allocation ledger.

This ledger maps each in-scope source file to exactly one primary capability from the product-capability taxonomy. Secondary entries are explicit capability handoffs, not additional primary ownership. Headings identify materially separate allocation seams inside composite documents.

The ledger treats cross-capability navigation, governance, architecture diagrams, runbook catalogs, and persona hubs as explicit overview or index lenses. They are classified as `index`, `reference`, or `normative design` and use the nearest capability as an allocation anchor; they are not treated as taxonomy defects.
