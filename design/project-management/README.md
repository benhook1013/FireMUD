# Project Management Docs

This section tracks planning materials, AI rules, and other documents used to organize development of the FireMUD platform.

Key files include:

- **ai-rules-global.md** and **ai-rules-local.md** – Coding and documentation guidelines.
- **core-requirements.md** – High-level feature requirements.
- **task-list.md** – Active and planned development tasks.
- **design-assumptions.md** and **design-document-research.md** – Supporting materials and research notes.
