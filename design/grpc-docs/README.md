# gRPC API Documentation

This directory contains generated reference documentation for all public gRPC APIs exposed by the FireMUD microservices.

The content is derived from the protobuf definitions under the top-level `protos/` directory and is intended as a stable contract reference for client and service developers.

## Documents

- [grpc-api.md](./grpc-api.md) – Combined HTML/Markdown view of all service, request, response, and enum types generated by `protoc-gen-doc`. **Do not edit this file manually.** Regenerate it after changing any `.proto` files.

For schema evolution rules and guidance on error handling, see the architectural [gRPC API Style & Versioning Guidelines](../architecture/system-architecture-grpc.md). For service-level behavior, consult each microservice’s `README.md` under `design/architecture/microservices/` and the corresponding `services/<service>/` implementation.
