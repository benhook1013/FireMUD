# Design Documentation

This directory contains all architecture and project-management documentation for the FireMUD Game Platform.

- **architecture/** – Infrastructure, microservice designs, and system overviews.
- **project-management/** – Requirements, task lists, and AI rule sets.
- **user-guides/** – Documentation for game creators and integration testing.

Additional generated documentation lives in:

- **grpc-docs/** – API references generated from our protobuf definitions.
- **observability/** – Default Grafana and Kibana dashboard templates.

Refer to the README files within each subdirectory for more details. For a high-
level walkthrough of common creator and player workflows see
[**User Journeys**](architecture/user-journeys.md).
