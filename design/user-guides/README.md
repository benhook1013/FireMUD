# User Guides

The user-guides directory collects documentation aimed at creators, administrators, and other non-engineering users of the FireMUD platform.

These guides explain how to configure hosted games, customize worlds, and interact with the system without requiring deep knowledge of the underlying microservices.

## Documents

- [game-creator-guide.md](./game-creator-guide.md) – Walkthrough for setting up and customizing a game world using the Game Design tools, scripting APIs, and related architecture docs.

As new guides are added (for moderators, analytics consumers, or support teams), list them here with a short description and link to the relevant architecture or project-management documents.
