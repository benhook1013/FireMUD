## Environment Variables

The service publishes assets to an S3-compatible store configured via:

- `ASSET_STORE_ENDPOINT`
- `ASSET_STORE_BUCKET`
- `ASSET_STORE_REGION`
- `ASSET_STORE_ACCESS_KEY`
- `ASSET_STORE_SECRET_KEY`
